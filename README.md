## Course Breakdown

### C1 – Introduction to Data Analytics
Overview of the data analytics lifecycle, data roles, and data structures. Covers data collection, wrangling, mining, and visualization fundamentals.

### C2 – Excel Basics for Data Analysis
Data cleaning, spreadsheet analysis, filtering, lookups, pivot tables, and spreadsheet-based data exploration.

### C3 – Data Visualization and Dashboards with Excel and Cognos
Creation of visualizations and interactive dashboards using Excel and IBM Cognos Analytics to communicate business insights.

### C4 – Python for Data Science, AI & Development
Python programming fundamentals, including data structures, control flow, functions, OOP basics, APIs, and web scraping using Jupyter notebooks.

### C5 – Python Project for Data Science
Hands-on project applying Python, Pandas, and visualization tools to collect, analyze, and present real-world data insights.

### C6 – Databases and SQL for Data Science with Python
Relational database design and SQL querying, including joins, views, transactions, and database manipulation using SQL and Python.

### C7 – Data Analysis with Python
Data cleaning, exploratory data analysis, statistical analysis, regression modeling, and predictive analytics using Pandas, NumPy, SciPy, and Scikit-learn.

### C8 – Data Visualization with Python
Data storytelling using Matplotlib, Seaborn, Plotly, and Folium to build charts, maps, and interactive dashboards.

### C9 – IBM Data Analyst Capstone Project
End-to-end data analytics project involving data collection, wrangling, analysis, visualization, and dashboard creation to solve real-world business problems.

### C10 – Generative AI: Enhance your Data Analytics Career
Application of Generative AI tools in data preparation, analysis, visualization, and ethical considerations in analytics workflows.

### C11 – Data Analyst Career Guide and Interview Preparation
Preparation for entry-level data analyst roles, including resume development, interview readiness, and career strategy.
